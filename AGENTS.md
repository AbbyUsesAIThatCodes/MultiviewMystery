# Working On Multiview Mystery

Follow [Shared Edugames Standards](docs/EDUGAMES-STANDARDS.md), including the
three purposes: Free Explore, Learn, and Challenge. Preserve supported alternative
solutions and the fixed top/front/right drawing convention.

Read [Curricular Mapping](docs/CURRICULAR-MAPPING.md) before expanding learning
scope. The missing DM 1.2/2.1 goals audits must not be represented as complete.

Follow [Build Identity](docs/BUILD_IDENTITY.md) for any artifact-producing build.
Run `node verify.mjs`, syntax checks, and the focused browser checks when changing
interaction. Inspect desktop and phone layouts. Keep reference navigation keyboard
and touch accessible, retain original font licenses, and preserve offline assets.

Keep changes on review branches; do not merge or deploy without teacher direction.
Store reusable graphics in EdugamesGraphicsStorage with provenance and checksums.
