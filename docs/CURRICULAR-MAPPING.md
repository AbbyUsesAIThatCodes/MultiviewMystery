The original game README describes conceptual alignment. This is not evidence of
an approved goal-by-goal audit. The table below describes existing mechanics and
local learning intentions, **not official curriculum goals or codes**. Replace
provisional intentions with exact document/edition/goal references once reviewed.

| Local Learning Intention | Student Action | Observable Evidence | Limit |
| --- | --- | --- | --- |
| Relate a solid to fixed views | Rotate a cube model and choose Top, Front, or Right | Identify what each drawing shows | No recorded verbal explanation |
| Anticipate a view | Choose one of three drawings in Learn | Correct selection after examining the model | A supported practice choice, not independent assessment |
| Reconstruct shape from drawings | Add/remove cubes in Challenge | All three projections and visible depth-change edges match | Does not test dimensioned drawing or hidden-line conventions |
| Recognize construction constraints | Check a model and revise it | Supported, face-connected cubes within the grid | Workshop rules are not universal manufacturing rules |
| Investigate cause and effect | Change a free construction and inspect live drawings | Notice which views change | Open exploration has no mastery score |

Keep original primary curriculum sources in the course repository. This game and
its public graphics pack contain no copied PLTW worksheets or assessment answers.
